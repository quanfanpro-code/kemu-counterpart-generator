# 序时账分析器 CLI 版使用说明

`ledger-cli.exe` 是「序时账分析器」的纯命令行版本，供 agent / 脚本自动调用，**不依赖图形界面**。
处理成功返回退出码 `0`，失败返回退出码 `1`。

---

## 一、基本用法

```
ledger-cli.exe <输入文件> <输出文件> [选项]
```

示例：

```bash
# 用默认设置处理（只输出一张结果表）
ledger-cli.exe 序时账.xlsx 结果.xlsx

# 完整输出（含异常明细、班福分析等所有表），并提高异常阈值
ledger-cli.exe 序时账.xlsx 结果.xlsx --mode full --threshold 20000
```

---

## 二、参数说明

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| `input` | 是 | 输入 Excel 文件路径 | 无 |
| `output` | 是 | 输出 Excel 文件路径 | 无 |
| `--threshold <数值>` | 否 | 异常分录筛选阈值（金额绝对值超过该值才被视为异常） | `10000` |
| `--mode <summary\|full>` | 否 | 输出模式，见下方「输出模式」 | `summary` |
| `--log-level <级别>` | 否 | 日志级别：`DEBUG` / `INFO` / `WARNING` / `ERROR` | `INFO` |
| `-i, --interactive` | 否 | 列识别不出时弹出命令行选单逐列选择；不加则缺列直接报错 | 关闭 |

---

## 三、输出模式

- **`summary`（默认）**：只输出一张「生成结果」表（含对方科目、匹配类型列），速度快。
- **`full`**：输出全部 sheet：
  - 生成结果
  - 原始数据
  - 异常分录明细
  - 异常分录（汇总）
  - 班福分析
  - 失败分组（仅当存在失败分组时）

> 注意：CLI 版输出为**普通格式** Excel（无图表、无美化），与图形界面版不同。

---

## 四、退出码

| 退出码 | 含义 |
|--------|------|
| `0` | 处理成功，结果已写入输出文件 |
| `1` | 处理失败（例如：读取失败、缺少必要列、金额值无法识别） |

agent 可依据退出码判断是否继续后续流程。

---

## 五、输入 / 输出格式

- **输入**：`.xlsx` / `.xls` 等常见 Excel 格式（内部优先用 calamine 引擎读取，读不了会回退到 openpyxl）。
- **输出**：`.xlsx`（用 openpyxl 写入）。

---

## 六、必需列说明

输入文件需要包含以下列，否则会报错：

```
会计月、凭证种类、凭证编号、一级科目、借方发生额、贷方发生额
```

规则：
- **凭证种类**：缺失时 CLI 会自动按「无/不适用」处理，不报错。
- **其他必需列缺失**：默认直接报错并以退出码 `1` 结束；如需手动指定，加 `-i` 参数会弹出命令行选单逐列选择。
- 金额列无法识别的值（非数字、非空白）会被判定为错误并退出。

---

## 七、给 agent 的调用注意事项

1. **编码**：程序以 UTF-8 输出中文日志，agent 读取时请按 **UTF-8** 解析，否则可能乱码。
2. **首次启动慢**：单文件程序首次运行会自行解压，开头几秒无输出属正常，请耐心等待。
3. **不依赖 Excel 安装**：本工具用 pandas/openpyxl 处理表格，不需要电脑上安装 Microsoft Excel。
4. **交互模式慎用**：`-i` 会弹出命令行选单等待人工输入，agent 自动调用时一般不要加，否则会卡住等待输入。
5. **路径含中文**：如果输入/输出文件路径含中文，agent 调用时请确保自身环境按 UTF-8 处理命令行参数，避免乱码。

### Task 2: 修正取值区间（GREEN）

**Files:**
- Modify: `make_excel.py:577-579`（`_chart_xml` 内解析系列引用的三行）

**Interfaces:**
- Consumes: `_abs_ref(ref) -> (sheet, "$D$1:$D$10")`。
- Produces: 无新接口；`_chart_xml` 输出行为修正为「名称 `$D$1`、取值 `$D$2:$D$10`」。

- [ ] **Step 1: 替换取值区间解析**

把 `make_excel.py` 中这三行：

```python
        cells = rng.split(":")
        name_ref = cells[0]
        val_rng = cells[-1] if len(cells) > 1 else cells[0]
```

替换为：

```python
        cells = rng.split(":")
        name_ref = cells[0]
        # 系列首行是名称，取值取第二行到末行（原写法误取成最后一个单元格）
        val_rng = name_ref
        if len(cells) > 1:
            列 = cells[0].split("$")[1]
            首行 = int(cells[0].split("$")[2]) + 1
            末行 = int(cells[-1].split("$")[2])
            if 首行 <= 末行:
                val_rng = "$%s$%d:$%s$%d" % (列, 首行, 列, 末行)
```

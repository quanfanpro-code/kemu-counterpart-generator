# 原凭证冲销反查实施计划

> **For agentic workers:** 未授权子代理，按 executing-plans.md 串行执行。

**Goal:** 对方科目分析程序能核实摘要所引原凭证，并把冲销业务与同张凭证的新业务分开。

**Architecture:** 先运行原有凭证处理，再根据严格核对的冲销分组调整目标凭证结果；原有凭证处理器不改。源凭证结果可逐行追溯时，冲销行沿用其对方科目关系。

**Tech Stack:** Python 3.14、pandas、现有 pytest。

**Spec:** `docs/superpowers/specs/2026-10-21-原凭证冲销反查-design.md`

## Global Constraints

- 同一账套、确切日期和凭证字号、明细科目、原摘要、等额反向金额都须核实；候选唯一。
- 不增加依赖，不改原始账，未核实的凭证沿用现有流程。

# 班福定律图表修复 — 设计方案

## 结论

采用**方案 A：就地修正取值区间解析**。只改 `make_excel.py` 的 `_chart_xml` 一处，不动图表定义的对外契约，不动新版外观。

## 方案比较

### 方案 A：就地修正取值区间（推荐）

在 `_chart_xml` 中把系列取值区间由「末格」改为「首格下一行 ~ 末行」：`$D$1:$D$10` → 名称 `$D$1`、取值 `$D$2:$D$10`。

- 影响面：`make_excel.py` 一处，3 行左右。
- 优点：改动最小、对外契约零变更、回归测试仍走真实导出链路；可逆。
- 缺点：区间解析逻辑仍留在 `_chart_xml` 内。

### 方案 B：抽出 `_系列区间(cells)` 辅助函数

把「名称 / 取值」的解析独立成函数，由 `_chart_xml` 调用。

- 优点：职责单一，可单独断言。
- 缺点：当前只有一个图表定义（班福图）会用到，属于为一次调用建立抽象，违反 YAGNI。

### 方案 C：改图表定义契约，名称与取值引用分开写

图表定义改成 `"名称引用": "'班福分析'!D1"`、`"取值引用": "'班福分析'!D2:D10"`。

- 优点：引用关系显式，彻底消除「系列首行是名称」的隐式约定。
- 缺点：需同时改调用点与既有测试；与 Excel / openpyxl `titles_from_data` 的通行习惯相反；本次只需修 bug，不必扩大契约变更。

### 推荐理由

方案 A 只修数据源错误、零契约变更，回归测试依然覆盖真实导出链路。等将来出现第二个图表定义再考虑抽函数。

## 数据流

```
图表定义(tp.图表) → _abs_ref 绝对化 → _chart_xml 拼 <c:ser> → xl/charts/chart1.xml
```

修复只落在 `<c:ser>/<c:val>/<c:numRef>/<c:f>` 的取值区间。以下保持不变：

- `<c:cat>` 分类引用：`$B$2:$B$10`（本来就是纯取值）。
- `<c:tx>` 名称引用：`$D$1`、`$E$1`。
- 系列外观：配色、圆点标记、线宽；图框尺寸 15 × 8.9 cm。

## 错误处理

- 系列引用只有一格（`D1`）时，名称与取值同为该格，保持现有行为，不新增崩溃路径。
- 引用退化成一行区间（`D1:D1`）时，起点会越过终点，此时退回输出该单格，避免写出非法区间。

# 文件夹批处理验收复核

## 范围与结论

按需求、设计和计划逐项核对新增批处理模块、列名窗口、主桌面入口、相关测试、README 和主入口版本。由当前助手串行审查，未启动独立复核助手。原配对算法、凭证分组、筛选规则和独立 CLI 未修改。

最终 57 项测试全部通过，其中原有 41 项及本次新增 16 项。没有发现尚未修复的阻塞问题。本结论只覆盖源码和真实桌面窗口自动化测试，不代表旧 EXE 已更新或生产账业务含义已核实。

## 已发现并修正

1. 同名 `.xls`、`.xlsx` 采用格式后缀区分时，可能与另一份原名恰好包含格式后缀的文件碰撞。真实文件测试复现后改为统一核对已分配路径，重名追加序号，避免重复目标。
2. 原筛选界面测试把窗口复选框总数写死为两个。新增开关后改为定位原筛选选项，继续验证原单文件实际导出。
3. 多次连续打开、关闭桌面窗口时，窗口循环引用可能在后台线程分配期间回收，导致 Tkinter 变量销毁调用报线程警告。严格测试复现，核对官方线程模型后，在新窗口启动前由主线程回收上一窗口；严格警告检查不再报错。
4. 普通 Tk 按钮宽度按字符数而不是像素计算，新增操作组按现有双界面分支分别设宽，避免把像素值当成字符数。
5. 清单采用临时文件写完后替换，不直接中途破坏上一份完整清单；CSV 字段加文本保护，避免文件名或错误文本被解释为公式。

## 验收对应

| 需求 | 实测结果 |
| --- | --- |
| 默认根层、可勾选递归 | 扫描测试和两个真实桌面入口测试通过 |
| 独立结果、层次和输入不变 | 打开工作簿核对对方科目，逐文件字节比较输入，重复批次目录不同 |
| 排除临时文件与历史结果 | 根层、子层与历史结果目录扫描测试通过 |
| 坏文件和非法金额继续 | 清单列出两个失败与两个成功，失败原因包含金额字段 |
| 列名按格式复用与取消 | 同格式一次、不同格式分别确认；取消只影响该格式 |
| 筛选整批一次 | 真实列名和筛选窗口在主线程各出现一次，两份结果均含筛选表 |
| 运行保护 | 文件夹入口运行时禁用；结束状态不被旧进度覆盖 |
| 空输入 | 不创建结果目录，明确无候选 |
| 部分分组错误 | 实际触发分组异常，仍保存失败分组表，清单标为部分失败 |
| 保存失败 | 不发布该份正式结果，下一份正常输出 |
| 原有入口 | 原有 41 项测试保持通过 |

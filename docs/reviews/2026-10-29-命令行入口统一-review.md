- `docs/superpowers/plans/2026-10-29-命令行入口统一.md`

## 发现与修复

### 旧 CLI 无参数会启动 GUI

初版转调只调用 `main.main()`，无参数时进入主程序 GUI 分支，不符合无头入口。先新增 `test_旧CLI无参数不启动图形界面`，观察到 3 秒超时失败后，在旧入口强制追加 `--no-gui`。修复后返回 argparse 退出码 `2`，不再启动窗口。

### 旧测试仍要求独立 CLI 的不同完整输出

`tests/test_三维分录判断.py` 原断言独立 CLI full 不含主程序索引列。转调后完整输出按新需求与主程序一致，因此把预期改为：full 保留主程序索引，summary 不含索引。没有为迁就旧断言恢复重复实现。

## 需求逐项核对

- 主程序默认 `full`：原异常检测、班福分析和完整美化写出保留，既有图表与批处理测试通过。
- 新增 `summary`：真实主程序命令只生成普通“生成结果”，不含图表；显式筛选时追加筛选表。
- 共用逻辑：读取、处理、校验和输出模式选择集中在共享流水线；完整与简版共用生成结果列排序。
- 旧 CLI：仅保留路径引导、`main.main()` 转调和强制 `--no-gui`，独立参数、映射、处理与输出代码已移除。
- 版本号：主程序与 GUI 读取 `src.__version__`；旧 CLI 经转调显示同一版本。
- 文档：README 当前用法、筛选命令、目录说明、CLI 说明和更新记录已同步；历史更新记录保留历史事实。
- 旧 exe：`cli/ledger-cli.exe` 无差异，未重新打包。

## 正确性、安全与性能

- 未改匹配算法、输入数据含义或网络行为，未新增依赖、密钥、外部服务或命令执行路径。
- 未知输出模式在处理前明确抛出 `ValueError`；损坏输入真实退出码为 `1`，参数错误为 `2`。
- summary 不再额外计算异常与班福分析；full 计算路径未改。
- 输出工作簿在表头居中后显式关闭，保存失败仍记录日志并返回 `False`。
- 未处理范围外的旧文件覆盖、pandas 弃用警告或同表多图问题。

## 简化审查

旧 CLI 从 214 行降为 14 行，完整输出没有另造普通 full 写入器，也没有保留兼容抽象或重新打包。新增代码只覆盖 summary 必需分支，符合最终需求。

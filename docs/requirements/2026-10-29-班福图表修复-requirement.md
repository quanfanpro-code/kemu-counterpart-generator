# 班福定律图表修复需求

## 背景与使用场景

2026-10-21 的提交「Excel 输出层重写为一次成型写入」把 `make_excel.py` 从 openpyxl 逐格写值改为标准库拼 XML 一次打包，班福折线图随之改由自制 XML 拼装（`_chart_xml`）。

对照旧版实现（该提交的父提交，用 openpyxl 的 LineChart）发现：新版把系列取值引用解析成了**单个单元格** `$D$10`、`$E$10`，而原版是整列 `$D$2:$D$10`、`$E$2:$E$10`。用户打开新版导出的文件，确认班福图与旧版「完全不是一回事」。

对照证据由「用 openpyxl 生成同一张表同一张图并解包 chart1.xml」得到，已核实。

## 范围与约束

- 只改「序时账分析器」的图表拼装逻辑：修正系列取值区间解析，使 `D1:D10` 这类系列引用解析为「名称 = D1，取值 = $D$2:$D$10」。
- 保留新版外观选择：圆点标记、配色（4472C4 / ED7D31）、线宽与图框尺寸，均不作调整。
- 分类引用（`B2:B10`，本来就是纯取值）不动；表格数值、格式、其它 sheet 一律不动。
- 不改动其它项目：全工作区只有本工具用到这套图表拼装。
- 不新增依赖，不引入外部资料，不改动匹配与拆分算法。

## 验收标准

1. 导出的班福图，两个系列的取值引用为整列区间（`$D$2:$D$10`、`$E$2:$E$10`），分类引用为 `$B$2:$B$10`。
2. 新增回归测试：取值区间写错时测试必须失败，能覆盖「名称取首行、取值取其余行」这一规则。
3. 用真实序时账导出一份带图表的样表放到桌面，由用户打开确认图形正确。
4. 既有测试全部通过。

## 调研依据与待确认项

依据：本仓库 `make_excel.py` 的 `_chart_xml` / `_abs_ref`；旧版写法取自 git 提交 204a2c6 的父提交；对照证据来自 openpyxl 生成同表同图后解包 `xl/charts/chart1.xml`。

待确认项：无。外观基准（保留新版风格）与验收方式（导出样表由用户核对）均已确认。
